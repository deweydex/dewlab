What holds for every cell, and what doesn't

Numbered
Every cell, every type — the identity pill never depends on whether anything has run.
Type colour
Only the type half of the pill, not the number — Python reuses the app's own orange, Text stays neutral, SQL/HTML/CSS each get one muted hue of their own so a mixed notebook scans by colour as well as by label.
Drag target
The whole pill, dots included — not the dots alone.
Run line
Only cells that run against the shared session (Python, SQL). Text, HTML, and CSS render from their own content and have nothing to report there.
Collapse
Only where there's code to hide: Python, SQL, CSS.
Edit / View
Only where there's a rendered form to toggle away from: Text and HTML. Code cells are always their own source.
Quiet by default
Text and HTML only — chrome is opacity-hidden, not display:none, so it stays reachable by Tab even while invisible.
Stale
Folded into the run line as a third reading — "ran Nth in X ms — edited since" — not a separate badge.
