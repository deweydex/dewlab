Working with Lists

Lists you can change

A list holds many values in one place, in the order you put them.

You can add to a list, take from it, or change one of its values. Try it below, then read on to see what each of those actions is called.

fruits = ["apple", "pear", "plum"]
fruits.append("fig")
print(fruits)

Notice that append() always adds to the end — if you want to change a value that's already there, you name its position instead.

fruits[1] = "mango"
print(fruits)

A position like that is called an index, and counting starts at zero — so fruits[1] is the second item, not the first.
