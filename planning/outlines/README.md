# Outlines

One file per tutorial that does not exist yet. Each says what the tutorial is
for, what its sections would be, and what the runnable cells would do — enough
that somebody could sit down and write it, and enough that Josh can disagree
with the shape before any of it is written.

They are outlines, not drafts. Nothing here is student-facing yet, so the
register is ours rather than theirs.

`planning/curriculum/proposed.yaml` says where each one would go in the series
and why that position. `planning/CURRICULUM_MAP.md` shows what each would close.
