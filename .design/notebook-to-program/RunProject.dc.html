from grades import average, band def read_marks(path): with open(path) as f: return [int(line) for line in f] def main(): marks = read_marks("marks.csv") score = average(marks) print("Average:", score) print("Band:", band(score)) if __name__ == "__main__": main()

main() is the cell order, written down. That is the sentence the whole sequence exists to earn.
The wrinkle that must not be a footnote. Python caches imported modules, so after editing grades.py a second import silently gives the old version. Unhandled, the student meets code that is visibly right and behaves as though it is wrong — a worse mystery than the one this feature solves.
Effort, roughly: importing a workspace .py is close to free — one sys.path entry at boot, plus that reload handling. The extraction dialogue is where the work and the teaching both sit.
