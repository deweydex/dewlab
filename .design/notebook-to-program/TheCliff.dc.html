One edit, two failures — in cells they did not touch, with messages that name none of the cause.
The name average stopped being a number and became a function. Everything that quietly relied on it being a number fails at once.
Or worse

The old numeric average may still be in memory, so nothing breaks — until the next restart, when everything does, and they cannot tell which change caused it.

This is the shape of the problem. The notebook lets you write code that works because of hidden global state, and the move to a program withdraws all of that state at once.

It is not a path. It is a cliff.
