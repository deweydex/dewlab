Where the code lives

notebook → program

The same five lines of a student’s code, at three stages. What changes is not the logic — it is where the logic lives and what holds it together. Today dewmini supports only the left column.

1 Now
The notebook
marks = [72, 65, …]
total = 0 … average = …
if average >= 70: band = …
print(average, band)

Every name is global. Nothing marks which lines belong together.

The program is the cell order — and the cell order is not written down anywhere.

2 After extracting
The notebook
marks = [72, 65, …]
from grades import average
average(marks)
band(average(marks))
extracted, one at a time
grades.py

  …

def band(score):
  …

The notebook still runs after every move. One thing changes at a time, so a break has one cause.

3 As a program
main.py

def main():

grades.py
