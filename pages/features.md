# What dewlab can do

dewlab keeps the tools for reading, trying and practising a subject in one
place.

## What you can learn

<ul class="dl-feature-list">

- **Every cell runs Python.** A real Python, called Pyodide, runs right
  inside the page, in your own browser. No server executes your code, and
  nothing you write is sent anywhere.
- **Learn HTML and CSS.** Web Authoring teaches you to build a page and
  publish a small site.
- **Learn SQL.** Database Methods runs SQL queries beside the Python that
  reads their results.

</ul>

## Tools on every page

<ul class="dl-feature-list">

- **Look up what you have learned.** The Reference panel holds a glossary
  of every term and function this page and earlier ones have covered.
- **Keep your own notes.** Write down anything worth remembering as you
  read. Notes are saved in this browser.
- **Take your saved work with you.** Export your answers and notes as a
  file, then load that file back on another device.
- **Export what you build.** Save a standalone page, print or save a PDF,
  or save your code as a Jupyter notebook.

</ul>

The lists below are grouped by who you are. Choose the one that fits you.

## For students

<ul class="dl-feature-list">

- **Start without setup.** Open a page in the browser. There is nothing to
  install and no account to create.
- **Read, edit and run.** Explanations sit beside editable code, with
  results shown on the same page.
- **Practise with support.** Practice pages provide more problems, with
  hints and answers available when needed.
- **Come back to your work.** Edits and results are saved in this browser
  and are not submitted or scored.
- **Work online or offline.** Download a tutorial, a series or a complete
  module and continue without an internet connection.
- **Take work elsewhere.** Save a standalone HTML copy, print or save a
  PDF, or export cells as a Jupyter notebook.
- **Choose how you read.** Settings include themes, typefaces, text size,
  line width, contrast and link colour.
- **Find the right material.** Search directly, follow a course in order,
  browse by topic or use the topic tree.
- **Work without a tutorial.** The [dewlab Notebook](compose/notebook.html)
  is a small space for Python, notebooks, files, uploads, SQLite and web
  pages. The [dewlab Workspace](compose/workspace.html) is a focused place
  for HTML, CSS and JavaScript.

</ul>

## For teachers

<ul class="dl-feature-list">

- **Teach in a clear sequence.** Courses and series put tutorials in the
  order they are intended to be taught.
- **Connect lessons to the curriculum.** Tutorial sections identify the
  QQI learning outcomes they cover.
- **Keep explanation and activity together.** Students can read, run an
  example and try a related problem on one page.
- **Support different routes through the material.** Search, browse by
  topic or use the topic tree when course order is not the right route.
- **Teach when the connection is unreliable.** Download a tutorial, series
  or complete module before class.
- **Demonstrate freely in the Notebook.** Use [the blank
  Notebook](compose/notebook.html) for examples, files, notebooks, SQLite
  and small web pages without attaching them to a tutorial.

</ul>

## For administrators

<ul class="dl-feature-list">

- **Reduce classroom setup.** Learners need a modern browser rather than a
  local programming environment.
- **Avoid learner accounts.** dewlab does not require registration or
  sign-in.
- **Keep learner work local.** Code and results stay in the browser on the
  device being used.
- **Use a static site.** The published learning pages need no application
  server or database.
- **Plan for limited connectivity.** Downloadable tutorials and course
  bundles can be prepared in advance.

</ul>
