# A Third Page

Prose only, and here for one reason: the contents page draws a map of a series
once it has three tutorials in it, and two is not three. Without this the map
would be untestable in a browser, which is where its one hard rule lives — that
being wider than the reading measure must not make the page itself scroll
sideways.

It also names Tutorial 1 below, which is what makes a "builds on" arrow appear,
so both kinds of arrow are exercised rather than only the reading-order one.

## Where this came from

The idea was first introduced in Tutorial 1, and this page leans on it.
