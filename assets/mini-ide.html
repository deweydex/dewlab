Mini IDE

This is the larger of dewlab's two Python workspaces — the fuller toolbar and export options here suit a project meant to stand on its own, outside any one tutorial. Looking for something quieter, for a quick calculation or a single practice problem? dewmini is the smaller, more minimal notebook built on the same Python runtime.

Welcome to the Mini IDE

This is a simple development environment where you can create and run Python code cells, along with text cells for documentation. It works entirely in your browser with nothing to install.

  • Python Cells: Write and execute Python code. Cells share a common namespace, so variables and functions defined in one cell are available in others.
  • Text Cells: Write documentation, comments, or explanations in plain text.
  • Execution: Click Run on any cell to execute it, or Run All to execute all cells in order. Run becomes Stop while a cell is running.
  • Reordering: Drag and drop cells to rearrange them.
  • Files: Upload files or drag them onto the Files pane; a real folder on your computer or private browser storage backs it, depending on what you choose in Settings.
  • Persistence: Cells are automatically saved in your browser's local storage; files live in whichever storage backs the Files pane.
  • Import: Load a .ipynb or .py file as this notebook's cells.
  • Downloads: Export your cells as a Python file, an HTML snapshot, or a Jupyter Notebook.

Available Functions: You can use show(), show_table(), run_query(), check(), text_input(), dropdown(), button(), and load_csv() just like in the tutorials — plus sqlite3 from Python's own standard library.
