Welcome to the Mini IDE

This is a simple development environment where you can create and run Python code cells, along with text cells for documentation. It works entirely in your browser with nothing to install.

  • Python Cells: Write and execute Python code. Cells share a common namespace, so variables and functions defined in one cell are available in others.
  • Text Cells: Write documentation, comments, or explanations in plain text.
  • Execution: Click Run on any cell to execute it, or Run All to execute all cells in order.
  • Reordering: Drag and drop cells to rearrange them.
  • Persistence: Your work is automatically saved in your browser's local storage.
  • Downloads: Export your work as a Python file, standalone HTML, or Jupyter Notebook.

Available Functions: You can use show(), show_table(), check(), text_input(), dropdown(), button(), and load_csv() just like in the tutorials.
