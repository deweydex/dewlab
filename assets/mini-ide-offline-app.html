Mini IDE

This is the larger of dewlab's two Python workspaces — the fuller toolbar and export options here suit a project meant to stand on its own, outside any one tutorial. Looking for something quieter, for a quick calculation or a single practice problem? dewmini is the smaller, more minimal notebook built on the same Python runtime.

      Help

      Cells

      A Python cell runs when you press its Run button, or Shift+Enter from inside it — it turns into Stop while running. Run All runs every cell in order. Drag a cell by its header (the row with its Python/Text label) to move it.

      A text cell is documentation — it never runs. Click away from it and it renders (# heading, **bold**, *italic*, `code`, - bullets); click it again, or its Edit button, to get back to the plain text underneath.

      Files

      The Files pane is a real folder — upload into it, drag files onto it, or (in Settings) point it at an actual folder on your computer instead of this browser's own private storage. Load a saved notebook back in with Import, either replacing these cells or adding onto them (also set in Settings).

      What a cell can call

      The same small API dewlab tutorials use — numpy, pandas and matplotlib are already imported. Mini IDE also loads sqlite3 and Pillow, beyond what a tutorial page carries by default, so import sqlite3 and image work are there when a cell reaches for them.

      show(*values, label=)

      show_table(frame)
      Render a DataFrame as a table
      run_query(conn, sql)
      Run SQL, shown as a table
      check(actual, expected)

      text_input(label)
      A text box, read with .value
      dropdown(label, options)
      A menu, read with .value
      button(label, on_click)
      A button that calls a function
      image_input(label)
      A file picker for an image, read with .value
      await load_csv(name)
      Load a CSV from dewlab's shared data folder, if one's there

      Keeping your work

      Cells are saved to this browser as you go; files live in whichever storage backs the Files pane. Settings has ways to take a copy with you: a Python file, a standalone HTML page, or a .ipynb that opens in Jupyter or Colab.
