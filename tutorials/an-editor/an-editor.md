# Choosing an editor

What do we need to write code? Code is plain text, whatever language it
is in. So any plain text editor can write it. Editors differ in how much
help they give us while we type. On this page we:

- meet VS Code, the editor most of this course has in mind
- meet GitHub's own editor, for when you cannot install anything
- compare what each one can do

## VS Code, on your own computer

[VS Code](https://code.visualstudio.com/) is a free editor. It works on
Windows, Mac and Linux, and most of this course has it in mind. It
colours each part of the code by what that part means. It can also help
us find a bracket with no partner, often before we notice one is
missing.

To set it up:

1. Download VS Code from the link above.
2. Install it the same way as any other program.
3. Open it once, to check that it starts.

You do not need to change any settings yet.

## GitHub's editor, with nothing to install

Can you not install programs on your computer? This happens often on a
school or work computer. GitHub has an editor inside its website, and it
works in the browser. There are two ways to open it:

1. Open a file in a repository, and press the pencil icon. Now you can
   edit that file.
2. Or, while you look at a repository's list of files, press the `.`
   key. This opens a larger version of the same editor.

Both versions colour code in the same way VS Code does. Every exercise in
this course works there too.

This editor has two limits:

- It works only on files that are already in a GitHub repository.
- It cannot show a preview of a page. On your own computer, you can open
  an HTML file in a browser and see it. The web editor cannot do this.

On the website track, the second limit matters less than it seems. You
can see your changes on your published site instead.
[Publishing your site with GitHub Pages](tutorial:publish-it) shows how.

## What we have now

We now have a way to write and change the files this course asks for,
with or without installing anything.

| Editor | Where it runs | Needs installing? | Preview of a page? |
|---|---|---|---|
| VS Code | your own computer | yes | yes, by opening the file in a browser |
| GitHub's editor | GitHub's website, in the browser | no | no, but the published site shows changes |
