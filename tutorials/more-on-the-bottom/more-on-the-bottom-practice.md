# Negative powers: more on the bottom — Practice

Small problems on one idea. A negative power is one over the power:
♡⁻³ is 1/♡³. Try each problem before you open anything under it.
Choose numbers, shapes or letters in the box under the title.

## 4. When the exponent is a letter

The worksheet has exponents we do not know.

<div class="dl-world" data-world="numbers">

Here are six divisions. What do the first three have in common? And
the last three?

$$\frac{5^{10}}{5^{11}} \qquad \frac{5^{20}}{5^{21}} \qquad \frac{5^{99}}{5^{100}}$$

$$\frac{2^{4}}{2^{7}} \qquad \frac{2^{10}}{2^{13}} \qquad \frac{2^{50}}{2^{53}}$$

```question
id: when-the-exponent-is-a-letter-1--numbers
type: fill-in-the-blank

Each of the first three is
{5⁻¹|5|5⁻²¹}.

Each of the last three is
{2⁻³|2³|2⁻¹¹}.
```

</div>

<div class="dl-world" data-world="squiggles">

$$\frac{\heartsuit^{\triangle}}{\heartsuit^{\triangle + 1}} \qquad \frac{\triangle^{\square}}{\triangle^{\square + 3}} \qquad \frac{\bigstar^2}{\bigstar^{\heartsuit + 2}}$$

```question
id: when-the-exponent-is-a-letter-1--squiggles
type: fill-in-the-blank

The first one is
{♡⁻¹|♡|♡^(2△+1)}.

The second one is
{△⁻³|△³|△^(−□)}.

The third one is
{1/★^♡|★^♡|★⁻²}.
```

</div>

<div class="dl-world" data-world="letters">

$$\frac{k^{m}}{k^{m + 1}} \qquad \frac{r^{p}}{r^{p + 3}} \qquad \frac{p^2}{p^{m + 2}}$$

```question
id: when-the-exponent-is-a-letter-1--letters
type: fill-in-the-blank

The first one is
{k⁻¹|k|k^(2m+1)}.

The second one is
{r⁻³|r³|r^(−p)}.

The third one is
{1/p^m|p^m|p⁻²}.
```

</div>

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Choose a number for the unknown exponent, like 4. The first one
   becomes 4 on the top and 5 on the bottom.
2. Cross out pairs. How many are left, and where?
3. Now choose 10 for the unknown exponent. Is the answer different?

**Think about:** the top and the bottom start the same. The bottom has
a few more. Only those few are left.

**Try this next:** ♡^△ over ♡^(△+10).

</details>

<details class="dl-answer"><summary>one way through it</summary>

Subtract the exponents. For the first one, $m - (m + 1) = -1$, so
$k^m / k^{m+1} = k^{-1} = \frac{1}{k}$. For the second, $p - (p + 3) =
-3$, so the answer is $r^{-3} = \frac{1}{r^3}$. For the third, $2 - (m
+ 2) = -m$, so the answer is $p^{-m} = \frac{1}{p^m}$. The unknown
exponent does not matter. Only the difference matters.

</details>

More from the worksheet. Each one comes to a single negative power.

<div class="dl-world" data-world="numbers">

$$\frac{2^2}{2^5 \cdot 2^2} \qquad \frac{3^{10} / 3^4}{3^{10}} \qquad \frac{10^3}{10^4} \qquad \frac{2^5 \cdot 3^3}{2^7 \cdot 3^3}$$

```question
id: looks-scary-is-simple-1--numbers
type: fill-in-the-blank

The first one is
{2⁻⁵|2⁻³|2⁻¹⁰}.

The second one is
{3⁻⁴|3⁴|3⁻¹⁶}.

The third one is
{10⁻¹|10|10⁻⁷}.

```

</div>

<div class="dl-world" data-world="squiggles">

$$\frac{\heartsuit^2}{\heartsuit^5 \cdot \heartsuit^2} \qquad \frac{\triangle^{10} / \triangle^4}{\triangle^{10}} \qquad \frac{\square^3}{\square^4} \qquad \frac{\heartsuit^5 \triangle^3}{\heartsuit^7 \triangle^3}$$

```question
id: looks-scary-is-simple-1--squiggles
type: fill-in-the-blank

The first one is
{♡⁻⁵|♡⁻³|♡⁻¹⁰}.

The second one is
{△⁻⁴|△⁴|△⁻¹⁶}.

The third one is
{□⁻¹|□|□⁻⁷}.

The fourth one is
{♡⁻²|♡⁻²△⁻³|♡⁻²△}.
```

</div>

<div class="dl-world" data-world="letters">

$$\frac{m^2}{m^5 m^2} \qquad \frac{n^{10} / n^4}{n^{10}} \qquad \frac{w^3}{w^4} \qquad \frac{q^5 r^3}{q^7 r^3}$$

```question
id: looks-scary-is-simple-1--letters
type: fill-in-the-blank

The first one is
{m⁻⁵|m⁻³|m⁻¹⁰}.

The second one is
{n⁻⁴|n⁴|n⁻¹⁶}.

The third one is
{w⁻¹|w|w⁻⁷}.

The fourth one is
{q⁻²|q⁻²r⁻³|q⁻²r}.
```

</div>

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Make the top into one power, then the bottom. Two powers multiplied
   together join into one stack. Add their exponents.
2. For the second one, do the division on the top first.
3. Now there is one power on the top and one on the bottom. Subtract
   the exponents.

**Think about:** in the fourth one, the second shape is on the top and
on the bottom the same number of times. What happens to it?

**Try this next:** (♡⁴ × ♡⁴)/♡¹⁰.

</details>

<details class="dl-answer"><summary>one way through it</summary>

With letters:

- $m^5 m^2 = m^7$, so $\frac{m^2}{m^7} = m^{-5}$.
- $n^{10} / n^4 = n^6$, so $\frac{n^6}{n^{10}} = n^{-4}$.
- $\frac{w^3}{w^4} = w^{-1}$.
- The three $r$s on the top cross out with the three on the bottom.
  That leaves $\frac{q^5}{q^7} = q^{-2}$.

With numbers, the answers are $2^{-5} = \frac{1}{32}$, $3^{-4} =
\frac{1}{81}$, $10^{-1} = \frac{1}{10}$ and $2^{-2} = \frac{1}{4}$.

</details>

## 8. A negative base

From the worksheet: what is $\dfrac{(-3)^2}{(-3)^5}$? The base is
−3 this time.

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. The base is a number like any other, so the crossing out works the
   same way.
2. Subtract the exponents: 2 − 5.
3. Write the answer as one over a power. Then find that power: −3 × −3
   × −3.

**Think about:** a negative times a negative is positive. Three
negatives multiplied together are negative.

**Try this next:** $\dfrac{(-2)^3}{(-2)^5}$.

</details>

<details class="dl-answer"><summary>one way through it</summary>

$$\frac{(-3)^2}{(-3)^5} = (-3)^{-3} = \frac{1}{(-3)^3} = \frac{1}{-27} = -\frac{1}{27}$$

This answer is negative. The minus sign in the exponent did not do
that. The base, −3, did.

</details>

You can check it here. The first line gets Python's fraction tool
ready.

```python exec
id: a-negative-base-1
from fractions import Fraction

print(Fraction((-3) ** 2, (-3) ** 5))
print(Fraction(-3) ** -3)
```

## 9. A stretch: a fraction for a base

From the worksheet: what is $\dfrac{(1/2)^4}{(1/2)^7}$? The answer may
surprise you.

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Subtract the exponents, as before: 4 − 7.
2. Write the answer as one over a power. The power is $(1/2)^3$.
3. From the folded paper, $(1/2)^3 = \frac{1}{8}$. So the answer is 1
   over $\frac{1}{8}$.

**Think about:** how many eighths make one whole pizza?

**Try this next:** $\dfrac{(1/2)^2}{(1/2)^5}$.

</details>

<details class="dl-answer"><summary>one way through it</summary>

$$\frac{(1/2)^4}{(1/2)^7} = \left(\frac{1}{2}\right)^{-3} = \frac{1}{(1/2)^3} = \frac{1}{1/8} = 8$$

1 over $\frac{1}{8}$ asks how many eighths make 1. Eight slices of
$\frac{1}{8}$ make a whole pizza, so the answer is 8. A negative power
of a number smaller than 1 is bigger than 1.

</details>

## 10. Swap the top and the bottom

From the worksheet: how does $\dfrac{q^{10}}{q^{12}}$ compare to
$\dfrac{q^{12}}{q^{10}}$?

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Find each one with the subtracting rule.
2. Write the first one as one over a power.
3. Choose a number for $q$, like 3. What are the two amounts now?

**Think about:** what you get if you multiply the two together.

**Try this next:** compare $\dfrac{\heartsuit}{\heartsuit^4}$ and
$\dfrac{\heartsuit^4}{\heartsuit}$.

</details>

<details class="dl-answer"><summary>one way through it</summary>

$\frac{q^{10}}{q^{12}} = q^{-2} = \frac{1}{q^2}$, and
$\frac{q^{12}}{q^{10}} = q^2$. They are the same fraction, with the top
and the bottom swapped. With $q = 3$, they are $\frac{1}{9}$ and 9.
Multiplied together, they make $q^{-2} \times q^2 = q^0 = 1$. Here is
one answer. Yours may be different and work too.

</details>

## 11. What went differently here?

Somebody found $2^{-3}$ like this. "$2^3$ is 8. The minus sign makes it
negative. So $2^{-3}$ is −8." Is $2^{-3}$ the same amount as −8?

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Write $2^{-3}$ as one over a power.
2. Find that power.
3. Is the answer below zero, or above it?

**Think about:** the continued pattern in problem 6. Did any line go
below zero?

**Try this next:** what is $-2^3$, with the minus sign in front?

</details>

<details class="dl-answer"><summary>one way through it</summary>

No. $2^{-3} = \frac{1}{2^3} = \frac{1}{8}$. That is a small amount, but
it is above zero. The minus sign in the exponent says the 2s are on the
bottom. It does not make the number negative. A minus sign in front of
a number does make it negative, so many people read it that way. Here
is one answer. Yours may be different and work too.

</details>

## 12. From earlier: a simpler name

From *Equivalent fractions: the same amount, different names*. What is
the simplest name for $\frac{9}{27}$? Now look again: 9 is $3^2$ and 27
is $3^3$. What does the subtracting rule say?

<details class="dl-answer"><summary>one way through it</summary>

Divide the top and the bottom by 9: $\frac{9}{27} = \frac{1}{3}$. The
subtracting rule says $\frac{3^2}{3^3} = 3^{-1} = \frac{1}{3}$. Both
paths give one third.

</details>

## 13. From earlier: a fraction for a base

From *Powers: the long way and the short way*. What is
$\left(\frac{1}{10}\right)^3$? Which negative power of ten is it?

<details class="dl-answer"><summary>one way through it</summary>

$\frac{1}{10} \times \frac{1}{10} \times \frac{1}{10} = \frac{1}{1000}$.
That is $\frac{1}{10^3}$, which is $10^{-3}$: one millimetre, in
metres.

</details>
