# Unknowns: a box with something in it — Practice

Small problems on one idea. A box, a shape or a letter holds a number
we cannot see. The = sign says both sides are level, so only one number
fits. Try each problem before you open anything under it. Choose
numbers, shapes or letters in the list under the title. With numbers,
the box is a ?.

<img src="box-and-three.svg" alt="A balance with its bar level. The left pan holds one closed box, marked with a question mark, and 3 beads. The right pan holds 7 beads.">

## 1. Same or different?

Each sentence below is compared with □ + 3 = 7, the balance in the
picture.

```question
id: same-or-different-1
type: fill-in-the-blank

3 + □ = 7 says
{the same as|something different from}
□ + 3 = 7.

7 = □ + 3 says
{the same as|something different from}
□ + 3 = 7.

□ = 7 + 3 says
{something different from|the same as}
□ + 3 = 7.
```

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. In □ + 3 = 7, the box holds 4.
2. Put 4 in the box of each sentence.
3. Are both sides of that sentence the same?

**Think about:** does it matter which pan the box is on? Does it
matter if the beads sit before or after the box?

**Try this next:** does 7 = 3 + □ say the same as □ + 3 = 7?

</details>

<details class="dl-answer"><summary>one way through it</summary>

With 4 in the box, 3 + 4 = 7, and 7 = 4 + 3. Both say the same as
□ + 3 = 7. But □ = 7 + 3 puts 10 in the box, and 10 + 3 is 13, not 7.
So it says something different.

</details>

## 3. A guess, and a check

Somebody wants the box in □ + 9 = 14. They guess 6.

```question
id: a-guess-and-a-check-1
type: fill-in-the-blank

With 6 in the box, the left side is 6 + 9, which is
{15|14|69}.

That is
{more than 14|less than 14|the same as 14}.

So the box holds
{less than 6|more than 6|exactly 6}.
```

What is the next guess to try? What does the box hold?

<details class="dl-answer"><summary>one way through it</summary>

6 was too many, by 1. So try 5. With 5 in the box, 5 + 9 = 14. The bar
is level, so the box holds 5.

</details>

## 4. Continue the pattern

Each line has one more loose bead than the line before it. The right
side stays 5.

$$\square + 1 = 5 \qquad \square + 2 = 5 \qquad \square + 3 = 5$$

```question
id: continue-the-pattern-1
type: fill-in-the-blank

In □ + 1 = 5, the box holds 4. In □ + 2 = 5, it holds 3. In □ + 3 = 5,
it holds 2.

In □ + 4 = 5, the box holds
{1|0|9}.

In □ + 5 = 5, the box holds
{0|1|10}.
```

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Each line adds one more loose bead to the left pan.
2. The right pan still holds 5 beads.
3. So each box holds one bead fewer than the box before it.

**Think about:** what happens when the loose beads alone already make
5.

**Try this next:** □ + 6 = 5. This is a stretch.

</details>

<details class="dl-answer"><summary>one way through it</summary>

The boxes hold 4, 3, 2, 1 and then 0. In □ + 5 = 5, the 5 loose beads
already balance the right pan, so the box is empty.

The next one, □ + 6 = 5, needs a number less than 0. Numbers less than
0 are called *negative* numbers. That box holds −1, one less than
nothing. Then −1 + 6 = 5.

</details>

## 6. Match three ways

A balance holds two boxes, the same, and 5 loose beads on the left
pan. The right pan holds 11 beads. The bar is level.

```question
id: match-three-ways-1
type: multiple-choice
answer: 1

Which of these says the same as the balance?

- □ + □ + 5 = 11
  - Two boxes and 5 loose beads on one side, 11 beads on the other.
- □ + 5 = 11
  - That is one box. The balance has two.
- 2 + 5 = 11
  - The 2 counts the boxes. But each box holds some beads, and 2 + 5
    is 7.
- □ + □ = 11 + 5
  - The 5 loose beads sit beside the boxes, on the same pan.
```

How many beads are in each box?

<details class="dl-answer"><summary>one way through it</summary>

Each box holds 3. Two boxes of 3 and 5 loose beads make 3 + 3 + 5,
which is 11. The bar is level.

</details>

## 7. What went differently here?

Here is a worked problem.

> □ + 4 = 10. So □ = 14.

What would you show the person who wrote it?

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Put 14 in the box.
2. Find 14 + 4. Is it 10?
3. The box and 4 loose beads make 10. Can the box hold more than 10?

**Think about:** the 4 loose beads are part of the 10, not extra.

**Try this next:** □ + 6 = 10.

</details>

<details class="dl-answer"><summary>one way through it</summary>

Put 14 back in: 14 + 4 is 18, and 18 is not 10. The worked line added
the 4 to the 10. But the 4 loose beads are already part of the 10
beads on that side. The box holds the rest: 6. Then 6 + 4 = 10.

</details>

3. One whole pizza is 4 of those slices. One slice is already there.

**Think about:** how far the loose part is from the other side.

**Try this next:** □ + 1/3 = 1.

</details>

<div class="dl-world" data-world="letters">

same thing.

</details>

## 10. A guessing machine

Here is the guessing machine from the page. It tries every whole
number from 0 to 20, and prints the ones that make both sides match.
In Python, `*` means times.

```python exec
id: a-guessing-machine-1
for guess in range(0, 21):
    if 6 * guess == 42:
        print("The box holds", guess)
```

It prints "The box holds 7". Change the check to test other problems
on this page. What does it print for `6 * guess == 40`? Why?

<details class="dl-answer"><summary>one way through it</summary>

For `6 * guess == 40`, it prints nothing. 6 × 6 is 36, and 6 × 7 is 42.
No whole number times 6 makes 40. The box holds a number between 6 and
7, and the machine only tries whole numbers.

</details>

## 11. A stretch: two different shapes

$$\square + \triangle = 10$$

The square and the triangle are different boxes. They can hold
different numbers. Can you find three answers? How many answers are
there, if each box holds a whole number of beads?

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Put 3 in the square. What must the triangle hold?
2. Now put 4 in the square. What must the triangle hold now?
3. Can the square hold 0? Can it hold 10?

**Think about:** each number in the square gives one number for the
triangle.

**Try this next:** what if □ and △ must hold the same number?

</details>

<details class="dl-answer"><summary>one way through it</summary>

□ = 3 and △ = 7 is one answer. □ = 7 and △ = 3 is another. So is
□ = 0 and △ = 10. With whole numbers, the square can hold 0, 1, 2 and
so on, up to 10. That makes 11 answers. One level bar is not enough to
find two different boxes. If both boxes must hold the same number,
there is one answer: 5 and 5.

</details>

## 12. From earlier: a box in a power

From *Powers: the long way and the short way*. A box can sit anywhere,
even in the exponent.

$$2^{\square} = 8 \qquad 10^{\square} = 1000$$

What does each box hold?

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Start with 2 × 2. What is it?
2. Multiply by 2 again. What is it now?
3. Count the 2s you multiplied.

**Think about:** the exponent counts how many times we multiply.

**Try this next:** 3 to the power □ is 81.

</details>

<details class="dl-answer"><summary>one way through it</summary>

2 × 2 × 2 = 8, so the first box holds 3. And 10 × 10 × 10 = 1000, so
the second box holds 3 too.

</details>
