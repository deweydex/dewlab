# An editor

HTML and CSS files are plain text, and a plain text editor is all you
need to write them. The difference between editors is how much help they
give you while you type.

## VS Code, the usual choice

[VS Code](https://code.visualstudio.com/) is free, works on Windows,
Mac and Linux, and is what most of this course assumes. It colours code
by what it means, and it usually points out an unmatched bracket before
you notice one is missing.

Download it from the link above, install it as you would any other
program, and open it once to check it starts. Nothing else needs
configuring yet.

## No installing anything: GitHub's own editor

If you cannot install software, for example on a school or work computer,
GitHub has an editor built into its website. Open a file in a repository
and press the pencil icon to edit it there. Pressing `.` while looking at
a repository's file list opens a fuller version of the same editor. Both
highlight code the way VS Code does, and every exercise in this course
works there too.

The trade-off is that this editor only works on files already in a
GitHub repository. It also cannot preview a page the way opening a file
directly from your computer can. For the web track, this matters less
than it sounds. [Publish it](tutorial:publish-it) covers a loop where you
see your changes on the published site instead.
