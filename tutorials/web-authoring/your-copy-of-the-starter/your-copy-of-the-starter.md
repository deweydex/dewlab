# Your copy of the starter

The web track begins with
[`portfolio_wad`](https://github.com/deweydex/portfolio_wad), a small
three-page site you edit rather than build from nothing. Before any
exercise, you need your own copy of it.

## Two ways to get a copy

Press **Use this template**, GitHub's green button near the top of the
repository. This gives you a brand new repository, named whatever you
choose, with no visible link back to `portfolio_wad`. It becomes your own
from the first commit, which suits a site you may want to keep and show
people after the course.

Press **Fork**, the button beside it. A *fork* also copies every file
into your own account, but it stays visibly connected to the original
and keeps its history. Choose this if you might want to pull in a later
fix from `portfolio_wad` itself.

Either way, you end up with your own repository, free to rename now or
later. A name like `portfolio_wad` says which class it is for; something
plainer suits a site you plan to keep once the course ends.

Your copy behaves like any other repository from this point on. Changes
you make there never affect `portfolio_wad`, and any later change to
`portfolio_wad` never appears in your copy unless you ask for it. For
this course, that is exactly what you want: something entirely yours to
change.

## Three ways to open it

Once you have your copy, there are three ways to start editing it, and
none is more correct than the others.

**Clone it**, if you have Git installed and already know how to use a
terminal. This downloads the repository to your computer, so you edit
locally and push changes back up when ready.

**Download it**, if you want the files without Git. GitHub's green
**Code** button has a "Download ZIP" option, giving you a folder of
plain files to open in your editor.

**Edit it in the browser**, using GitHub's own editor, covered in [an
editor](tutorial:an-editor): no download at all, everything happens on
GitHub's website.

If you are not sure which to pick, editing in the browser is the
simplest starting point. You can always clone or download the same
repository later.

## What you have now

Your own copy of the starter, ready to open. [Publish
it](tutorial:publish-it) covers making that copy visible as a website,
which the starter's own first exercise asks you to do before changing
anything else.
