# Comparing fractions: which is bigger?

Two friends order the same pizza. Both pizzas are cut into 8 equal
slices. The shaded slices show what each friend ate.

<img src="same-bottom.svg" alt="Two pizzas of the same size, each cut into 8 equal slices. The first has 3 slices shaded. The second has 5 slices shaded.">

```question
id: two-pizzas-1
type: multiple-choice
answer: 2

Which friend ate more pizza?

- The first friend: 3 of 8
  - The first pizza has 3 slices shaded. The second pizza has more
    shaded slices, of the same size.
- The second friend: 5 of 8
  - The slices are all the same size, and the second pizza has more of
    them shaded.
- They ate the same amount
  - The two pizzas are the same size. The number of shaded slices is
    different.
```

## The same bottom number

We write the first friend's pizza as $\frac{3}{8}$. We write the second
as $\frac{5}{8}$. Both have the same bottom number, 8. So every slice is
the same size: one eighth of a pizza. We only need to count the slices.
More slices is more pizza.

```question
id: the-same-bottom-number-1
type: fill-in-the-blank

7/9 is {bigger than|smaller than|the same as} 4/9.

2/9 is {smaller than|bigger than|the same as} 4/9.
```

```question
id: the-same-bottom-number-2
type: fill-in-the-blank

Here are three amounts of pizza: 13/20, 9/20 and 11/20.

The smallest is {9/20|11/20|13/20}.

The biggest is {13/20|9/20|11/20}.
```

## The same top number

Now three pizzas of the same size. Each one is cut in a different way.
Each one has one slice shaded.

<img src="same-top.svg" alt="Three pizzas of the same size, each with one slice shaded. The first is cut into 3 equal slices, the second into 4, and the third into 6. The shaded slice is biggest on the first pizza and smallest on the third.">

```question
id: the-same-top-number-1
type: multiple-choice
answer: 1

Which shaded slice is the biggest?

- 1/3, one slice of 3
  - This pizza is cut into the fewest slices, so each slice is big.
- 1/6, one slice of 6
  - 6 is the biggest number here. This pizza is cut into the most
    slices, so each slice is small.
- They are all the same size
  - Each is one slice. The slices come from pizzas cut in different
    ways.
```

This is the surprise of this page. For one slice, a bigger bottom
number means a *smaller* slice. The bottom number says how many slices
the whole pizza was cut into. More slices means thinner slices. We saw
this on the page
[Fractions: one whole pizza, many slices](tutorial:one-whole-many-slices),
with a pizza cut into 1000.

```question
id: the-same-top-number-2
type: fill-in-the-blank

1/10 of a pizza is {smaller than|bigger than|the same as} 1/5 of a pizza.
```

**Think about:** what the bottom number counts.

## Three landmarks

Here is a line. It starts at 0 and ends at 1. 0 is no pizza. 1 is one
whole pizza. Halfway along is one half. Every fraction smaller than one
whole pizza has a place on this line.

We call 0, one half and 1 *landmarks*. A landmark is a place you can
see from far away, like a tall tower. On this line, the
landmarks help us see where a fraction is, without counting.

<img src="landmarks.svg" alt="A number line from 0 to 1. Ticks under the line mark 0, 1/2 and 1. Three dots above the line are labelled 1/4, 2/3 and 9/10. The dot for 1/4 is halfway between 0 and 1/2. The dot for 2/3 is a little past 1/2. The dot for 9/10 is close to 1.">

```question
id: three-landmarks-1
type: fill-in-the-blank

9/10 is closest to {1|1/2|0}.

2/3 is closest to {1/2|1|0}.
```

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. 9/10 is 9 slices out of 10. How many slices are missing from the
   whole pizza?
2. For 2/3, name everything in sixths. One half is 3/6. One whole is
   6/6. And 2/3 is 4/6.
3. How many sixths is it from 4/6 to 3/6? How many from 4/6 to 6/6?

**Think about:** which tick each dot in the picture is nearest to.

**Try this next:** is 1/10 closest to 0, to 1/2 or to 1?

</details>

```question
id: three-landmarks-2
type: multiple-choice
answer: 3

Look at the dot for 1/4. Which landmark is it closest to?

- 0
  - 1/4 is a small amount of pizza, so it can feel close to nothing.
- 1/2
  - 1/4 is half of a half, so it can feel close to one half.
- It is the same distance from 0 and from 1/2
  - From 0 to 1/4 is one quarter. From 1/4 to 1/2 is one quarter too.
```

## Where does it go?

Here is the same line, with no dots.

<img src="empty-line.svg" alt="A number line from 0 to 1, with ticks that mark 0, 1/2 and 1. There are no dots on it.">

```question
id: where-does-it-go-1
type: multiple-choice
answer: 2

Where would 3/4 go on this line?

- Between 0 and 1/2
  - 4 is a small number, so 3/4 can feel small. Half of 4 slices is 2,
    and 3/4 has 3.
- Halfway between 1/2 and 1
  - One half is 2/4, and 1 is 4/4. 3/4 sits in the middle.
- After 1
  - 3 and 4 are both bigger than 1. But 3/4 is one slice less than a
    whole pizza.
```

## Different tops and bottoms

Now a harder pair: 2/3 and 3/4. The tops are different. The bottoms
are different too. So the slices are different sizes, and we cannot
count them.

```question
id: different-tops-and-bottoms-1
type: multiple-choice
answer: 2

Make a guess before we look closer. Which is more pizza?

- 2/3
  - A third is a bigger slice than a quarter. But 3/4 has more slices.
- 3/4
  - 3/4 has one quarter missing. 2/3 has one third missing, and a third
    is bigger.
- They are the same amount
  - Each is one slice less than a whole pizza. The missing slices are
    different sizes.
```

On the page
[Equivalent fractions: the same amount, different names](tutorial:same-amount-different-names),
we gave one amount many names. Let's use that here. We give both
fractions a new name, with the same bottom number. Then the slices are
the same size, and we can count them.

Here is 2/3 on a fraction wall. The bottom bar is cut into twelfths.

<img src="two-thirds-in-twelfths.svg" alt="A fraction wall of three bars of the same length. The top bar is one whole. The next bar is cut into 3 thirds, with 2 shaded. The bottom bar is cut into 12 twelfths, with 8 shaded. The shaded parts of the two bars end at the same place.">

And here is 3/4, with twelfths under it too.

<img src="three-quarters-in-twelfths.svg" alt="A fraction wall of three bars of the same length. The top bar is one whole. The next bar is cut into 4 quarters, with 3 shaded. The bottom bar is cut into 12 twelfths, with 9 shaded. The shaded parts of the two bars end at the same place.">

```question
id: different-tops-and-bottoms-2
type: fill-in-the-blank

2/3 is the same amount as {8|6|9} twelfths.

3/4 is the same amount as {9|8|12} twelfths.

So the bigger one is {3/4|2/3}.
```

<details class="dl-hint"><summary>stuck? here are some steps</summary>

1. Look at the first wall. Count the shaded twelfths in the bottom bar.
2. Do the same with the second wall.
3. Now both fractions are counted in twelfths. The slices are the same
   size, as at the start of this page.

**Think about:** why twelfths work for thirds and for quarters. What is
3 × 4?

**Try this next:** which is bigger, 1/2 or 2/3? Try sixths.

</details>

Both fractions now have the same bottom number, 12. The slices are the
same size, as at the start of this page. So we can count them. 9
twelfths is more than 8 twelfths, by one twelfth.

```question
id: different-tops-and-bottoms-3
type: multiple-choice
answer: 2

Which is bigger, 3/5 or 2/3? Here, fifteenths work for both.

- 3/5
  - 3 is bigger than 2. But fifths are smaller slices than thirds.
- 2/3
  - 2/3 is 10 fifteenths, and 3/5 is 9 fifteenths.
- They are the same amount
  - They are close, one fifteenth apart. They are not the same.
```

3. How many fifteenths is 3/5? How many is 2/3?

## A machine that checks

On the page about equivalent fractions, we met a Python tool called
`Fraction`. It can also compare two fractions. The first line,
`from fractions import Fraction`, gets the tool ready. The sign `<` asks
Python a question: is the first fraction smaller than the second?

```python exec
id: a-machine-that-checks-1
from fractions import Fraction

print(Fraction(2, 3) < Fraction(3, 4))
```

```predict
type: choice

Before you run it: the cell asks "is 2/3 smaller than 3/4?" What will
Python print?

- True
  - 2/3 is 8 twelfths, and 3/4 is 9 twelfths.
- False
  - A bigger bottom number means smaller slices, and 4 is bigger than 3.
- 3/4
  - Python could name the bigger one, and not answer yes or no.
```

Python printed `True`. That means yes: 2/3 is smaller than 3/4.

Now try your own pairs. Change the numbers and run it again. What does
Python print for `Fraction(3, 5) < Fraction(2, 3)`? And for
`Fraction(1, 2) < Fraction(2, 4)`? Why do you think it prints that?

## Your rule, in your words

Before you read our version, say how you compare two fractions, in
your own words. Write it in the Notes panel or on paper, or say it
aloud.

<details class="dl-answer"><summary>one way to say it</summary>

If the bottom numbers are the same, the slices are the same size. Count
the slices: more slices is more pizza. If the top numbers are the same,
look at the bottoms. A bigger bottom number means smaller slices, so
less pizza. If the tops and the bottoms are both different, give the
two fractions new names with the same bottom number. Then count again.
Your way of saying it may be clearer than ours.

</details>

## Looking back

Somebody says that 1/6 is more than 1/3, because 6 is more than 3.
What picture would you draw for them?

A challenge: is there a fraction between 2/3 and 3/4? The program below
tests one guess. The last line asks two questions at once. Is 2/3
smaller than the guess? And is the guess smaller than 3/4? It prints
`True` only when both answers are yes. Can you find a guess that
prints `True`? Can you find three?

```python challenge
# Is there a fraction between 2/3 and 3/4?
from fractions import Fraction

guess = Fraction(4, 5)
print(Fraction(2, 3) < guess < Fraction(3, 4))
```
