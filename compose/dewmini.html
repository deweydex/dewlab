Add a Python cell to start writing code that runs in your browser, or a text cell for notes beside it. Cells share one namespace top to bottom, the way a notebook does — write something in the first cell and the next one can use it.

Help

Cells

A Python cell runs when you press its Run arrow, or Shift+Enter from inside it. Run all clears every cell's output and reruns them top to bottom, so what you see always matches what the code above it actually did. Drag a cell by its left edge to move it.

A text cell is documentation — it never runs. Click away from it and it renders (# heading, **bold**, *italic*, `code`, - bullets); click it again to edit the plain text underneath.

Hover the seam between any two cells (or before the first, or after the last) to insert exactly there — a blank Python cell, a text cell, or one already carrying the common imports.

Practice

Practice adds the next problem from dewlab's own practice bank — a documentation cell with the problem number, and a Python cell with the function stub to fill in. It works through the bank in order and remembers where you left off; run the cell yourself to check your work against the docstring's example.

Keeping your work

Everything you write is saved to this browser as you go — nothing is sent anywhere. Settings has ways to take a copy with you: as a Python file, a standalone HTML page, a .ipynb that opens in Jupyter or Colab, or a printed PDF with the code and its output. Give it a name there too. You can bring an existing .ipynb back in from the same place.
