    Cells

    A Python cell runs when you press its Run arrow, or Shift+Enter from inside it. Run all clears every cell's output and reruns them top to bottom, so what you see always matches what the code above it actually did. Drag a cell by its header — the row with its Python/Text pill — to move it.

    A text cell is documentation — it never runs. Click away from it and it renders (# heading, **bold**, *italic*, `code`, - bullets); click it again to edit the plain text underneath. Its picture-frame icon attaches an image from your device — it's kept with the cell, not uploaded anywhere.

    The seam between any two cells (or before the first, or after the last) inserts exactly there — a blank Python cell or a text cell. It's faint until you hover or tap it, not invisible; run a finger or a cursor down the page and you'll find every seam.

    Or a CSV from anywhere on the web

    Reaching the web works a little differently here, and it catches everyone once. Python is inside a browser tab, so it has no network connection of its own — it borrows the browser's. await load_csv(url) already does that for a CSV, and pyfetch is the general version: from pyodide.http import pyfetch, then response = await pyfetch(url) and await response.json(). To make pandas.read_csv("https://…") and requests work the way a snippet you copied expects, run import pyodide_http; pyodide_http.patch_all() once first (requests also needs await micropip.install("requests")). Either way the site you're reading from has to allow other pages to read it; if it doesn't, the error says so.

    Python runs off the page's own thread here, which is what gives you the Stop button — and what stops text_input, dropdown, button and image_input working, since a widget needs a live element on the page to listen on. Calling one tells you so. They work in a downloaded copy.

    Practice

    Practice adds a problem from dewlab's own practice bank — a documentation cell with the problem number, and a Python cell with the function stub to fill in. Settings has an Order switch: in order works through all 38 in sequence and remembers where you left off; random deals them out of order without repeating one until every problem has come up once. Run the cell yourself to check your work against the docstring's example.

    Keeping your work

    Everything you write is saved to this browser as you go — nothing is sent anywhere. Settings has ways to take a copy with you: as a Python file, a standalone HTML page, a .ipynb that opens in Jupyter or Colab, or a printed PDF with the code and its output. Give it a name there too. You can bring an existing .ipynb back in from the same place.
