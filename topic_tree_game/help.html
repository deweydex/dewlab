How to play

The game shows two topics and asks one question. Your answers help draw the map of what a student needs to learn first.

The question

Each turn shows two topics. Tap the one a student has to learn first. That topic becomes something the other one needs.

Read the short description under each name if you are not sure what it means. Do not tap the one that is easier or comes earlier in the course. Tap the one you could not do the other without.

The other answers

Unrelated
Neither topic needs the other. This is the most common answer, and it is a useful one.
Both ways
Each topic needs the other. That cannot be taught in any order, so it is a sign the two should be taught together or split apart.
Not sure
Skips this pair. It comes back later.
Refine the first or Refine the second
Opens a sheet for that topic. You can give it a name a student would recognise, tick the groups it belongs to, add a group that is not there yet, or flag it as needing work.

undo, at the top, takes back your last answer.

The counter

The bar and the number at the top say how far you are through the pairs worth judging. The game asks the most useful pairs first: the ones the map already claims, then pairs from the same part of a module. Everything else comes after, in a random order. Stop whenever you like. Your answers stay on this device.

Saving

After a dozen or so answers, tap save. Three ways are offered.

Send to GitHub
GitHub opens with a file already written. Sign in and tap Commit changes. A web address can only carry about a dozen answers, so a long session takes more than one tap. The sheet says how many.
Save a file
Downloads all your answers as one file. Send it on, or upload it to the folder the sheet names.
Copy everything
Copies your answers as text, for anyone without a GitHub account. Paste it into a message.

Nothing is sent anywhere until you choose one of these.

What happens next

Every saved batch is read by a script that writes a report. The report says what the answers imply. A person reads it and decides what changes on the map. Your answers are evidence, and they are always welcome, even when they disagree with what the map says now.
