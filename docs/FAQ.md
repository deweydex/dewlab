# Frequently asked questions

Here are answers to questions about learning with dewlab.
[Using dewlab](FOR_STUDENTS.md) explains the page controls in more detail.

## Do I need to know Python or maths already?

The first tutorials introduce the tools and ideas. Later tutorials build
on earlier ones. The topic tree shows which ideas a page usually needs.
You can return to an earlier explanation whenever it helps.

If you are learning in class, your teacher can help you choose where to begin.

## Is dewlab free? Do I need an account?

You can use the tutorials for personal learning without paying or making
an account. There is nothing to install. Reporting a problem through
GitHub does need a free GitHub account.

For teaching, adapting, or other uses, the [licence](../LICENSE.md)
explains the terms and how to contact the author.

## Are my answers graded?

dewlab does not grade tutorial or practice answers. Some activities offer
a check that helps you compare your result with the expected one.

If a result is different, a hint or worked example may help you decide
what to try next. You can also ask for help. If your teacher uses these
materials for a class task, they can explain what is assessed.

## What if I need a break?

You can pause and return later. The page saves cell edits and notes in
this browser when storage is available. Settings shows the saving status
under **Your work**.

**Export a copy** lets you keep saved code, results, and notes in a file. Cells you add yourself have their own **Share** control. If saving
is not working, copying code and notes to a separate file can help you
keep them before leaving.

When you return, an earlier example or Reference entry may help you
remember where you were. You can take the time you need.

## Will my work appear on another computer?

Saved work stays in the browser and device where you used dewlab.
**Export a copy** and **Load a copy**, in Settings, let you move saved
code, results, and notes as a file. Loading replaces the matching
cell edits and notes, so you can export the current version first.

Cells you add yourself are stored separately. Their **Share** button
keeps an individual cell as a file. The Jupyter notebook export keeps
the code and text from all cells, including your own, for another program.

## Can I go ahead or return to an earlier page?

Yes. Pages in a series are listed in teaching order, but you can choose
which one to open. The topic tree shows earlier ideas a tutorial builds
on. **Browse by topic** helps you find more pages about one subject.

## Where does my code go?

Python runs in your browser. The tutorials save work on your device;
they do not automatically submit your answers to a teacher.

There are ways to share work. A cell's report link can send its code and
result to a GitHub form. A file you export can be shared by you. Code
that you choose to run may also make internet requests.

[Reporting a mistake or a bug](REPORTING_A_PROBLEM.md) explains what a
report includes. [Architecture](../ARCHITECTURE.md) describes the technical
behaviour.

## What does reset do?

A tutorial cell's **reset** button replaces your edits with its original
code and clears its visible result. It does not clear values already
held by Python. **Restart Python**, in Settings, starts a fresh Python
session while keeping your code in the editors.

**Start again** restores the tutorial's cells and clears your notes
after confirmation. It leaves cells you added yourself in place. The
[student guide](FOR_STUDENTS.md#resetting-code-or-restarting-python)
explains these choices and how to keep a copy first.

## I found a mistake. What can I do?

You can tell your teacher or use the report link at the bottom of the
page. You do not need to know the cause before asking about it.
[Reporting a mistake or a bug](REPORTING_A_PROBLEM.md) explains where to
send a report and what details may help.

## Can I use dewlab on a phone?

You can read tutorials and run cells on a phone. The panels open at the
bottom of the screen. A larger screen may be more comfortable for writing
code. Work saved on your phone does not appear automatically on a computer.

## What happens to my work when the course ends?

Work saved in your browser stays there until it is removed. Clearing
browser data removes that saved copy. Exported files give you copies to
keep outside the browser.

**Download to keep** saves the published tutorial and starter code. Your
own work uses the separate export options described in the student guide.

## What if a tutorial feels too hard or too easy?

A page may need more time or a different explanation. Reference, an
earlier tutorial, or your teacher can help you find a place to continue.
You can read a worked answer and then try the example again.

If you want more to explore, the practice page may offer a problem with
more steps. You could also change an example and see what happens.

## Can I try Python without following a tutorial?

[dewmini](DEWMINI.md) gives you space to write and run your own Python.
You can begin with a small example and add more as you need it.
